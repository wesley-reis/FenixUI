FenixUI · Smoke test dos ícones via CDN (UMD)

Bundle: …
Fonte esperada: …

Os ícones da lib são uma fonte de ligaduras (fenix-icons.woff2): o glifo é o próprio nome (home). Se o @font-face injetado apontar para uma URL errada (404), o glifo não existe e o navegador exibe o texto do nome — é exatamente o sintoma relatado.

1. Diagnóstico automático

O que olhar: @font-face src é o que a lib injetou no <head>; → URL resolvida pelo navegador é onde a fonte será realmente buscada. No bug, ela cai na SUA página (ex.: /app/fenix-icons.woff2) e o HTTP é 404. Corrigido, ela aponta para a pasta do bundle (…/dist/fenix-icons.woff2) com HTTP 200.
Testando um bundle local (?bundle=../dist/fenix-ui.umd.min.js aberto por file://): o fetch pode ser bloqueado pelo navegador — nesse caso use a aba Network. Para um teste fiel, sirva a página por HTTP (npx vite → http://localhost:5173/exemplos/cdn-icons.html).

2. Uso dos ícones — SEM workaround (estado atual do bundle)

Mesmo markup documentado para Vue/React. Se a fonte 404, tudo abaixo aparece como texto (home, search, navigate_next).

3. Uso dos ícones — COM workaround (fonte absoluta + --fx-icon-font)

Só a URL da fonte muda: um @font-face com a URL absoluta do fenix-icons.woff2 sob uma família própria, e o escopo abaixo aponta --fx-icon-font para ela. Nenhum markup muda — é a prova de que o problema é a URL, não o uso do componente. Este escopo funciona mesmo com o bundle quebrado.

4. Como validar no seu projeto (JSP / .NET / HTML puro)

  • DevTools → Network → filtro woff2: se o status for 404, a URL da fonte está caindo na sua aplicação (bug corrigido no bundle UMD a partir da próxima versão).
  • Console: document.getElementById('fenix-icons').textContent mostra o @font-face injetado; new URL(src, document.baseURI).href mostra a URL final.
  • Fonte carregada? document.fonts.check("24px 'Fenix Icons'") deve ser true; await document.fonts.load("24px 'Fenix Icons'", "home") deve devolver 1 face.
  • Global do UMD: typeof FenixUI deve ser object (FenixUI.theme('dark'), FenixUI.setTokens({…}), FenixUI.setFenixIconsFontUrl('/fonts/subset.woff2')). Se for undefined, o bundle é anterior à correção do global.
  • CSP: se você usa Content-Security-Policy, inclua font-src (e connect-src para o fetch do diagnóstico) com o domínio do CDN.
  • Subset (fonte de ~5 MB → dezenas de KB): depois de carregar o UMD, chame FenixUI.setFenixIconsFontUrl('/fonts/fenix-icons-subset.woff2') — com o path absoluto da sua aplicação (começando com / ou https://).
